# UI 设计案例库（2026）

独立文件夹，收录当前最优秀的应用 UI 设计案例，供前端界面迭代时参考。

## 文件结构

```
ui-design-cases/
├── index.html                      ← 可视化案例画廊（浏览器打开，可按维度筛选）
├── README.md
└── cases/
    ├── 01-apple-design-award-2026.md   Apple 设计大奖 12 款获奖作品 + 入围精选
    ├── 02-web-dashboard.md             Web/桌面 Dashboard 十大标杆 + 2026 趋势 + 布局速查
    └── 03-mobile-app-patterns.md       移动端案例 + 5 个可复用 UI 微模式 + AI 功能设计共识
```

## 案例选取标准

- 权威来源：Apple 设计大奖、Mobbin Awards（用户票选）、UX Design Awards
- 真实产品（非概念稿），且附带"可偷师"的具体模式
- 对 BootTracker 这类"记录 + 数据展示"工具最相关：Dashboard 组（Linear/Stripe/Plausible）与时间轴应用（Structured）优先收录
