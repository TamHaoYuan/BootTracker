# Apple 设计大奖 2026（ADA）获奖案例

> 来源：Apple Newsroom（2026-06）、App Store 年度故事。12 款获奖作品从 36 款全球入围中选出，覆盖 8 个国家。

## App 获奖（6 款）

| 类别 | 应用 | 开发者（国家） | UI 设计亮点 |
|---|---|---|---|
| 乐趣横生 | **grug** | Ocho（荷兰） | 肯定语应用。手绘原始风界面 + "新石器时代碎念"文案，一个极简想法做到极致，每天日出推送一句。**克制的单点体验设计范本** |
| 多元包容 | **Guitar Wiz** | Bijoy Thangaraj（印度，个人开发者） | 吉他学习工具。深度集成 VoiceOver 语音旁白、动态字体、增强对比度、不以颜色区分信息。**无障碍设计是核心而非附加项的标杆** |
| 创新思维 | **NBA: Live Games & Scores** | NBA Media Ventures（美国） | Vision Pro 空间版：同时看 5 场直播、悬浮实时数据榜、3D 球场桌面模式、空间音频。**空间计算 UI 的第一批成熟范式** |
| 出色互动 | **Moonlitt: Moon Phase Tracker** | Flipping Hues Srls（意大利） | 月相追踪。直观界面 + 符合平台习惯的轻量交互，信息呈现与操控高度合一 |
| 社会影响 | **Primary: News in Depth** | Wood Metal Rocks（美国） | 深度新闻。拒绝标题党，用空间视频 + 多维视角重构新闻阅读界面。**内容型产品去噪设计** |
| 视觉图像 | **Tide Guide: Charts & Tables** | Condor Digital（美国） | 潮汐图表。精致的图表绘制、一致的主题、高品质动画。**数据可视化美学标杆** |

## 游戏获奖（与 App 交互设计互鉴）

| 类别 | 游戏 | 开发者 | 亮点 |
|---|---|---|---|
| 乐趣横生 | Is This Seat Taken? | Poti Poti Studio（西班牙） | 卡通风解谜，俏皮交互彩蛋遍布界面本身 |
| 多元包容 | Pine Hearts | Hyper Luminal（英国） | 可调节文字可读性、控制方式、动效与感官反馈 |
| 创新思维 | Blue Prince | Dogubomb（美国） | 边探索边"搭建"宅邸的元解谜叙事 |
| 出色互动 | Sago Mini Jinja's Garden | Sago Mini（加拿大） | 幼儿交互设计，超大触控目标 |
| 社会影响 | Consume Me | Jenny Jiao Hsia 等（美国） | 用游戏机制呈现饮食失调的真实心境 |
| 视觉图像 | Cyberpunk 2077: Ultimate Edition | CD Projekt（波兰） | 移动端 3A 视觉与动画 |

## 值得研究的入围作品

- **Structured**（unorderly GmbH）— 日程/任务应用，时间轴 + 卡片式渐进披露，与 BootTracker 的记录场景高度相关
- **Blippo+**（Panic）— 复古硬件拟物 UI 的现代演绎
- **Sid Meier's Civilization VII** — 复杂策略信息的移动端适配
