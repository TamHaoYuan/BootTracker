# Web / 桌面工具 Dashboard 优秀案例（2026）

> 来源：AdminLTE、925 Studios、Shaheer Malik、Art of Styleframe 的 2026 年度盘点交叉验证。

## 十大标杆

### 1. Linear — 深色优先的力量工具标准
- 近单色表面 + 单一强调色；低对比面板边框；36px 紧凑行高
- 键盘优先导航，交互 <100ms，每个视觉选择都在传达"快"
- **可偷师**：去掉一切非必要元素，层级靠字重和间距而非边框阴影；同屏只展示一层细节

### 2. Stripe — 金融数据表格的教科书
- 表格即主界面：右对齐数字、tabular figures、内联 sparkline、不失位的下钻
- 首屏 4 张 KPI 卡 + 1 个核心图表，其余全用数字呈现
- **可偷师**：图表只做趋势摘要，表格才是真相；语义色状态胶囊（status pill）

### 3. Vercel — 极简单色系统
- 黑白设计系统，层级完全靠留白和字重；色彩只表达状态
- 部署摘要置顶、日志/构建详情一击即达（渐进披露）
- **可偷师**：空状态（empty state）设计占仪表盘"感知精致度"的 80%

### 4. Attio — AI 原生 CRM
- AI 摘要作为一等公民组件（非悬浮聊天挂件）
- **可偷师**：2026 趋势——AI 输出设计成结构化卡片、建议动作、生成式查询

### 5. PostHog — 密而不乱的产品分析
- 洞察卡片每张只回答一个问题；强默认值 + 清晰图表

### 6. Hex — 笔记本变仪表盘
- Notebook-to-dashboard 发布；AI 辅助分析工作台

### 7. Retool — 内部工具设计语言
- 务实的组件网格布局，跨异构数据保持一致

### 8. Mercury — 有编辑感的金融科技
- 柔和配色 + 自信层级，让银行数据"高级"；信任感来自设计而非功能堆砌

### 9. Plausible — 激进的单页仪表盘
- 公开的真实仪表盘，无侧边栏；证明窄场景下连侧边栏范式都可以打破

### 10. Supabase — 复杂控制台的寻路
- 一套页面模板承载多种工具，开发者控制台保持友好

## 2026 Dashboard 设计趋势

1. **AI 原生而非 AI 附加** — AI 输出是一等界面，不是覆盖在旧 UI 上的聊天窗
2. **深色优先** — 全天使用的工具（Linear/Vercel/Supabase）先做暗色再做亮色
3. **安静骨架 + 高密度** — 边框阴影持续收缩，层级靠字重间距，颜色只留给状态
4. **表格重夺王座** — 图表时代退潮，Stripe/Linear 式结构化表格回归
5. **渐进披露成为通用模式** — 首屏只回答"一切正常吗？"，细节按需展开
6. **角色感知** — 仪表盘按角色（创始人/运营/分析师）适配，而非千人一面

## 布局速查（可直接套用）

- 侧边栏：展开 240–280px（推荐 256px），收起 64px 图标模式
- 首屏：顶部 4–6 张 KPI 卡 + 下方 12 列 CSS Grid
- 主视图元素 ≤ 7–8 个；主指标放左上角（F 型扫描模式）
- 双主题从第一天就用 CSS 变量 + `data-theme`，跟随系统 `prefers-color-scheme`
