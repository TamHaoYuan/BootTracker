# BootTracker 适用 UI 设计整理

> 依据：`ui-design-cases/` 案例库（Apple 设计大奖 2026 / Web Dashboard 标杆 / 移动端模式）对照 BootTracker 前端现状（Vite+React18+AntD5，Dark Gallery 风格，`tokens.css` 七主题变体）。
> 目标：只收录**与本应用场景匹配**的模式，标注「已达标 / 可强化 / 建议引入」，附执行要点。日期：2026-09-25。

---

## 0. BootTracker 的产品定位决定设计取向

| 属性 | 对设计的含义 | 对标案例 |
|---|---|---|
| 数据记录工具（开机记录） | 用户回访看数据，秒级找答案 | Linear、Plausible |
| 时间序列数据（时长/次数/趋势） | 图表克制、表格为主 | Stripe、Tide Guide |
| 桌面常驻（托盘+小组件） | 小组件 = 单指标卡 | Mercury 首屏单指标 |
| 个人工具，非企业产品 | 无需信任脚手架堆砌，但删除操作需防护 | Viator 确认页模式 |
| 双主题（dark/light）+ 7 变体 | tokens 驱动是唯一可行路径 | Vercel 单色系统 |

**一句话取向**：仪表盘类工具 → 深色优先 + 单强调色 + 图表克制 + 表格回归。当前 Dark Gallery 基调正确，无需推翻。

## 1. 统计/首页 —— Dashboard 模式组

### KPI 卡条（来源：Stripe / 925 Studios 布局速查）✅ 建议引入
- 首屏顶部 3–5 张 KPI 卡：今日开机时长、7 日均值、连续开机天数、较昨日变化
- 公式：`大数字（tabular-nums） + 标签（muted） + 趋势箭头（▲8% 语义色）`
- 变化用语义色：上升/变好 = success `#6ee7b7`，恶化 = danger `#f87171`（已有 token）
- 数字字体：记录数据天然需要 `font-variant-numeric: tabular-nums`（JetBrains Mono 已引入，直接用于数字列）

### 主指标 + 趋势图（来源：Plausible）✅ 可强化
- 一个 hero 指标 + 一张趋势图，其余全部数字/表格呈现，**拒绝图表墙**
- 首页回答的唯一问题："最近开机情况正常吗？"（progressive disclosure：细节下沉到详情页）

### 表格回归（来源：Stripe）✅ 建议引入
- 开机记录列表用结构化表格：日期左对齐、时长数字**右对齐 + tabular-nums**、状态用语义色胶囊（低饱和底+高饱和字，如 `rgba(110,231,183,.12)` 底 + `#6ee7b7` 字）
- 行 hover 用 `--bg-card-hover`（已有 token），无斑马纹，1px `--border-light` 分隔
- 表格密度：36–40px 行高（桌面工具的舒适密度）

## 2. 记录时间轴 —— Structured 模式（ADA 入围，最直接相关）

开机记录本质是"按天发生的事件流"，Structured 的时间轴模式可直接借鉴：

- 纵向时间轴：左侧时刻轴线（`2px --border-muted`），当前时段高亮为 `--accent`
- 每条记录 = 卡片：开机时刻（等宽字体）+ 时长徽章 + 触发方式
- 当日分组头：日期 + 当日汇总（当日总时长，右侧对齐）
- 时间轴可视化和日历视图互补：日历看分布，时间轴看细节

## 3. 主题与色彩 —— 现状对照

### 已达标（无需改动）
- ✅ **CSS 变量 + `data-theme` 属性切换** —— 与案例库"双主题从第一天就用 CSS 变量"的最佳实践完全一致
- ✅ **深色优先**（`mode: 'dark'` 默认）—— 符合 2026 全天使用工具的趋势
- ✅ **统一缓动曲线体系**（`--ease-out-expo/spring/smooth/in-out-quart`）—— Airbnb"动效语法一致"原则已落地，继续坚持所有过渡引用这四个变量
- ✅ **语义色完整**（success/danger 各 3 档 + RGB 变体）—— 足够支撑"颜色=状态"

### 可强化
- **gray 主题 → Vercel 式单色系统**：当前 gray 主题 accent 取 `--text-muted`，方向正确。补一条纪律：**单色/灰主题下，色彩只出现在状态语义（success/danger），交互态靠字重与背景对比**——即 Vercel 的"层级完全来自留白与字重"
- **强调色纪律**（Linear 原则）：accent 只上可交互元素与当前选中项，不上装饰。检查各页面是否有 accent 色的纯装饰用法
- **每主题强调色数量收敛为 1**：当前有 `--accent` + `--accent2` 双强调色，Dashboard 类工具建议主界面只用 `--accent`，`--accent2` 留给图表双色场景

## 4. 小组件与托盘 —— Mercury 单指标模式

Rust 小组件（30s 拉取 `/api/data`）的界面设计：

- **只回答一个问题**：今日开机时长（或今日第 N 次开机）
- 结构 = Mercury 公式：`hero 数字 + 一个辅助行（第 N 次 · HH:mm）`，无图表无滚动
- 深色底 + 玻璃态（`--glass-*` tokens 可复用于 Rust 侧硬编码）
- 置顶小尺寸下字号阶梯：数字 ≥ 20px、辅助行 11px muted

---

## 5. 微模式清单 —— 直接可用的 5 条（来源：Mobbin 追踪）

1. **降低恐惧的 CTA 文案**：回收站永久删除按钮用「永久删除 3 条记录」而非「确定」；导出用「导出为 CSV」而非「继续」
2. **能自解释的错误文案**：数据加载失败时「无法连接本地服务（端口 18792），应用可能未启动完整」而非「出错了」
3. **诚实的进度**：备份/导入等长任务展示真实步骤，不做假进度
4. **删除的软护栏**：永久删除前展示将删除的条目摘要（Viator 确认页模式：review 应防止错误，而非复述输入）
5. **空状态设计**（Vercel：空状态占感知精致度 80%）：无记录时展示引导卡片「等待第一次开机记录…」+ 说明数据来源，而非空白表格

## 6. 无障碍 —— Guitar Wiz 教训（ADA 包容奖）

个人工具同样受益，低成本三件套：

- 对比度：muted 文字 `#8b8b94` 对 `#0a0a0c` 底 ≈ 4.6:1，达标；检查 `--text-disabled` 是否仅用于真禁用
- 焦点可见：所有可交互元素补 `:focus-visible`（当前 `--glass-focus` token 已有，确认全局应用）
- 数字不只靠颜色：趋势箭头 ▲▼ + 颜色双编码（色弱可读）

---

## 7. 不适用（明确排除，防止过度设计）

- ❌ AI 原生界面模式（Attio）—— 本应用无 AI 功能
- ❌ 空间计算多窗口（NBA Vision Pro）—— 桌面小组件已覆盖常驻需求
- ❌ 信任脚手架（KYC/合规类）—— 个人工具无监管流程
- ❌ 游戏化转盘/抽奖（Digcy）—— 与"克制的数据工具"气质冲突
- ❌ 品牌吉祥物（grug/Headspace）—— 工具型产品，记忆点应来自效率而非角色
